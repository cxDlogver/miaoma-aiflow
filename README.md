# miaoma-aiflow

妙码 AI Flow 课程实践项目，包含可视化 DAG 工作流、企业知识库 RAG、应用发布和 API 调用。使用 pnpm 9.12.3 与 Turborepo 管理 `apps/` 和 `packages/`。

## 获取项目

```bash
git clone https://github.com/cxDlogver/miaoma-aiflow.git
cd miaoma-aiflow
```

环境准备、依赖安装、数据库迁移、Ollama 配置与应用启动见[全链路使用与答辩手册](docs/妙码AI-Flow企业知识库RAG全链路使用与答辩手册.md#6-从零启动项目)。
